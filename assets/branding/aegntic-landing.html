02 / Research

Three problems that
define our work

Multi-agent systems. Agents that collaborate, negotiate, and self-organise. We study emergent coordination, task decomposition, and collective decision-making in heterogeneous populations -- the conditions under which groups of autonomous programs produce outcomes no single agent could reach alone.

Self-modifying systems. Safe autonomous code evolution with formal guarantees. How can an agent improve its own architecture while maintaining safety invariants, reproducibility, and the ability to roll back? This is not theoretical: clawREFORM ships a working kernel that does exactly this.

Agent-to-agent protocols. Open standards for inter-agent communication. Transport, discovery, and negotiation layers that let agents built by different teams -- in different languages, on different networks -- work together without a central orchestrator.

I

Open by default

Every project we release is free and open-source. No walled gardens, no API paywalls, no black-box models. The most important infrastructure for synthetic intelligence must be built in the open, where anyone can inspect, extend, and trust it.

II

Built to last

Rust-native, zero-dependency where possible, tested relentlessly. We optimise for the maintainer who inherits this code in five years, not the demo next week.

III

Ship, then evolve

Working systems over whitepapers. Proven code over speculative architectures. We believe the best research is the kind you can git clone and run today, not the kind that lives only in a PDF.
