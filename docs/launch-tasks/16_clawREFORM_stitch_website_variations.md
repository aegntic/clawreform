# Task 16: Stitch Website Variations

Create 3 visually distinct variations of the clawREFORM full website landing page on Stitch to explore different brand aesthetics and competitive positioning.

## Goal
Establish a high-impact visual identity that differentiates clawREFORM from OpenClaw and other competitors.

## Scope
- **Stitch Project**: `clawREFORM` (projects/13765533928830498267)
- **Base Screen**: `7_clawREFORM_design_lightspill.png` (screens/12552392466759995494)
- **Variations**:
    1. **Brutalist Minimalism**: Stark contrast, bold typography, raw edges.
    2. **Neo-Noir Gradient**: Deep purples, electric accents, tech-heavy/cyberpunk.
    3. **Technical Precision**: Grid systems, monospace fonts, data visualization.

## Preferred CLI / Agent
- **claude (glm-5.1)** / **opencode** (gemini-2.5-pro)

## Execution Instructions
1. Access the Stitch project.
2. Generate the 3 variations using the `generate_variants` tool or manual prompt orchestration.
3. Extract the design context for the winning variation to maintain consistency across other screens.
4. Capture screenshots of the new variations for the launch proof.

## Done Criteria
- [ ] 3 distinct variations generated in Stitch.
- [ ] Screenshots captured and stored in `output/launch/16-stitch-variations/screenshots/`.
- [ ] Handoff report created at `output/launch/16-stitch-variations/handoff.md`.
